## 🎰 로또

### ⚙️ 기능 구현 목록
#### 🧾 입력
- 로또 구입 금액을 입력받는다.
  - `ERROR` : 구입 금액이 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.
  - `ERROR` : 구입 금액이 숫자가 아니라면 예외 처리한다.
- 당첨 번호를 입력받는다.
  - 쉼표(,) 기준으로 6개의 숫자를 입력받는다.
  - `ERROR` : 쉼표(,)로 구분되지 않은 경우 예외 처리한다.
  - `ERROR` : 로또 번호가 1부터 45 사이의 숫자가 아니면 예외를 발생시킨다.
  - `ERROR` : 로또 번호에 중복된 숫자가 있다면 예외를 발생시킨다.
- 보너스 번호를 입력받는다.
  - `ERROR` : 당첨 번호와 중복되는 숫자가 있다면 예외를 발생시킨다.

##### 🎲 로또 게임
- 1장당 1,000의 가격으로 로또를 발행한다.
  - 중복되지 않는 랜덤한 숫자인 로또를 발행한다.
  - 발행된 로또 번호를 오름차순으로 정렬한다.
  - `ERROR` : 로또 번호가 1부터 45 사이의 숫자가 아니면 예외를 발생시킨다.
  - `ERROR` : 로또 번호에 중복된 숫자가 있다면 예외를 발생시킨다.
- 발행된 로또와 당첨번호를 비교한다.

##### 📊 출력
- 발행된 로또 수량과 각 번호를 출력한다. 
- 당첨 통계를 출력한다.
- 총 수익률을 출력한다.
